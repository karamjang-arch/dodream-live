# 두드림 선택특강 라이브

「하나님의 음성 듣기」 강의용 슬라이드와 참여용 페이지.

- 강의용: `index.html?r=dodream1` (2회차는 `?r=dodream2`, 연습은 `?r=test`)
- 참여용: `join.html?r=dodream1` (표지와 투표 슬라이드의 QR이 이 주소를 가리킴)

## 강의 중 키
- `→ / ←` 넘기기 · `F` 전체 화면 · `O` 목차
- `L` 강사 로그인(PIN). 로그인하면 투표 슬라이드로 넘어갈 때 휴대폰 질문이 자동으로 열리고, 다른 슬라이드로 가면 닫힌다.
- `R` 결과 막대 켜기/끄기
- `M` 보낸 글 관리(보이기/숨기기, 회차 초기화)
- `P` 승인한 글을 화면에 띄우기

## 데이터
Supabase(Jubilee-bridge)의 `live_` 표. 참여자는 표에 직접 접근하지 못하고 `sql/001_live.sql`의 함수로만 읽고 쓴다.
